# Brand logos (Simple Icons 16.37.0)

3,470 brand logos as single-colour SVGs in `svg/`, with each brand's official colour in `index.json` (`title`, `hex`, `file`).
Source: Simple Icons, released under CC0 (see LICENSE.md). OpenAI and Microsoft are not included: those companies asked Simple Icons to remove their logos.

Trademark rule for videos: logos are trademarks of their owners. Use a logo only to name the product being talked about
(for example, showing the Gemini logo while saying "Gemini"), never so that it looks like the brand made, sponsors or endorses the video.
Read DISCLAIMER.md and the brand's own guidelines before using a logo prominently.

To colour a logo: put `fill="<hex>"` on the `<svg>` element, or load it as an image in HTML/CSS, or as an image texture in Blender.
