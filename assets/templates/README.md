# Video templates and resources (downloaded 2026-11-13)

| Folder | What it is | License |
|---|---|---|
| remotion-templates | 81 ready Remotion templates (titles, text effects, transitions) | MIT (per README) |
| remotion-bits | Animated building blocks: charts, transitions, text reveals | MIT |
| motion | Curvable launch-video scenes for Remotion (14 scenes) | MIT |

Free asset sites to use (check each asset's license page before use):
- 3D: Poly Haven (CC0 models, textures, HDRIs), Kenney (CC0 3D/audio), Quaternius (CC0), ambientCG (CC0 materials), OpenGameArt (filter CC0; MagicaVoxel packs), Sketchfab/BlenderKit (filter to CC0)
- Sound: Kenney audio (CC0), Sonniss GDC bundles (royalty-free), Pixabay audio, Freesound (license per clip)
- Logos: assets/brand-logos (Simple Icons, CC0)
